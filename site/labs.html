Архивирование и восстановление данных

Открыть PDF

Оболочка: SQLServer2000Emu.exe (симулятор Microsoft SQL Server 2000).

Порядок выполнения:

  1. Создать распределенную базу данных, сформировать файлы на 5 рабочих станциях.
  2. Сгенерировать последовательность из 15+N транзакций над базой данных.
  3. Создать виртуальное устройство резервного копирования и выполнить полное резервное копирование БД.
  4. Внести новые изменения (10+N транзакций) и создать дифференциальную (добавочную) копию.
  5. Создать резервную копию журнала транзакций на отдельном устройстве и сымитировать системный сбой.
  6. Выполнить последовательное аварийное восстановление и ввести незафиксированные транзакции вручную до точки сбоя.
Лабораторная работа № 2

Управление учетными записями и аутентификация

Открыть PDF

Оболочка: NetSecurity.exe (имитатор службы безопасности).

Порядок выполнения:

  1. Войти в систему под учетной записью администратора (admin, sa, sysadmin).
  2. Создать учетные записи администраторов (АС, СА) и пользователей (ПРБ, ПОФ, ПАО, ПНС) согласно варианту.
  3. Объединить пользователей в группы безопасности (ГХД, ГАВ, ГРС, ГОС) и делегировать права доступа.
  4. Настроить политики паролей (минимальная длина, срок действия, глубина истории) и политику блокирования.
  5. Смоделировать атаку перебора пароля с блокировкой учетной записи и выполнить ее ручную разблокировку администратором.
  6. Сконфигурировать опции протокола Kerberos (запрос билета до/после входа, время жизни билетов TGT/TGS) и задокументировать «Журнал безопасности».
Лабораторная работа № 3

Исследование механизмов разрешения доменных имен

Открыть PDF Скачать DOC

Оболочка: Imitation.exe (папка «Имитатор сети» директории «АдминИС»).

Порядок выполнения:

  1. Запустить Imitation.exe и в окне «Администрирование сети» открыть схему из двух сетей.
  2. Для правой сети сконфигурировать зоны: ru. (192.0.0.0), ryazan.ru. (192.186.0.0), rgrtu.ryazan.ru. и рабочие станции asu (192.186.1.1), aitp, aimm, vpm.
  3. Для левой сети настроить зоны: by. (205.0.0.0), bgu.by. (205.100.0.0), fpmi.bgu.by. и хосты elektr, progr, matem, lingv.
  4. Заполнить общую базу данных на сервере 1-го уровня левой сети, разделить рабочие станции на открытую часть (флаг True) и закрытую часть (флаг False).
  5. Выполнить репликацию БД на все серверы через пункт «Работа с БД» и визуализировать соединения.
  6. Запротоколировать пошаговый обмен кадрами клиентского разборщика при обращении через Rlogin (запросы типа A и PTR к серверам зон и корневым узлам).
Лабораторная работа № 4

Настройка служб Active Directory, DNS и DHCP

Открыть PDF Скачать DOC

Оболочка: NetAdmin.exe (эмулятор сетевого администрирования).

Порядок выполнения:

  1. Запустить эмулятор, войти под именем Admin (пароль password) и запустить мастер dcpromo.exe.
  2. Создать новое доменное дерево в новом лесу с полным DNS-именем corp.com (NetBIOS-имя CORP).
  3. Задать каталоги размещения базы данных C:\Winnt\Ntds и папки Sysvol C:\Winnt\Sysvol.
  4. Выбрать режим «Настроить DNS вручную», добавить DNS-сервер и привязать IP-адреса пересылки данных (192.168.1.1 и 192.168.2.1).
  5. В окне управления DHCP авторизовать сервер Admin (смена индикатора с красного на зеленый).
  6. Создать область действия (Scope) по номеру варианта (Area 1 – Area 10), задать пул исключений и адрес шлюза.
  7. Выполнить аренду IP-адреса со стороны клиента и сымитировать пересылку сетевого пакета.

DHCP протокол

Открыть PDF

Цель: Обеспечить корректное автоматическое присвоение IP-адресов узлам сети на базе роутеров Cisco и выделенного сервера DHCP.

! 1. Настройка пула на маршрутизаторе 1841

Router(config)# ip dhcp pool DHCP
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8

! 2. Настройка перенаправления (ip helper-address) на маршрутизаторе 2911
Router(config)# interface gigabitEthernet 0/0.2
Router(config-subif)# encapsulation dot1Q 2
Router(config-subif)# ip address 192.168.2.1 255.255.255.0
Router(config-subif)# ip helper-address 192.168.4.2

Лабораторная работа № 11

Network Address Translation (NAT)

Открыть PDF

Цель: Настроить адресацию локальной сети на основе частных IP-адресов с трансляцией в публичные через технологию NAT.

! Определение внешнего и внутренних интерфейсов на Router0
Router(config)# interface fastEthernet 0/0
Router(config-if)# ip nat outside
Router(config)# interface fastEthernet 0/1.2
Router(config-subif)# ip nat inside

! Настройка списка доступа и трансляции с перегрузкой (PAT)
Router(config)# ip access-list standard FOR-NAT
Router(config-std-nacl)# permit 192.168.2.0 0.0.0.255
Router(config-std-nacl)# permit 192.168.3.0 0.0.0.255
Router(config)# ip nat inside source list FOR-NAT interface fastEthernet 0/0 overload
