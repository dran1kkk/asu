Раздел 3.2.4 · Лабораторная работа № 11

Network Address Translation (NAT Overload)

Открыть PDF

Цель работы: Реализовать трансляцию локальных частных IP-адресов в один публичный адрес внешнего интерфейса с перегрузкой по портам (PAT overload) для выхода рабочих станций во внешнюю сеть.

Конфигурация трансляции NAT:

! Определение внешнего и внутренних интерфейсов
Router0(config)# interface fastEthernet 0/0
Router0(config-if)# ip nat outside
Router0(config-if)# exit
Router0(config)# interface fastEthernet 0/1.2
Router0(config-subif)# ip nat inside
Router0(config-subif)# exit
Router0(config)# interface fastEthernet 0/1.3
Router0(config-subif)# ip nat inside
Router0(config-subif)# exit

! Стандартный список контроля доступа (ACL)
Router0(config)# ip access-list standard FOR-NAT
Router0(config-std-nacl)# permit 192.168.2.0 0.0.0.255
Router0(config-std-nacl)# permit 192.168.3.0 0.0.0.255
Router0(config-std-nacl)# exit

! Привязка трансляции с перегрузкой
Router0(config)# ip nat inside source list FOR-NAT interface fastEthernet 0/0 overload
Router0(config)# end
Router0# show ip nat translations
