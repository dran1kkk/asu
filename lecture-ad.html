Базы данных администрирования. Служба Active Directory

Active Directory Domain Services (AD DS) — распределенная иерархическая служба каталогов масштаба предприятия, предоставляющая централизованную базу данных сетевых ресурсов и единую точку аутентификации.

1. Логическая архитектура каталога

Логическое построение каталога не зависит от физического расположения серверов и сетевых коммутаторов:

  • Организационное подразделение (OU): минимальный контейнер для группировки объектов (пользователей, компьютеров) внутри домена, к которому привязываются объекты групповой политики (GPO).
  • Домен: базовая административная единица и граница безопасности, объединяющая объекты с общей базой данных NTDS.dit.
  • Дерево доменов: совокупность одного или нескольких доменов, использующих единое непрерывное пространство имен DNS.
  • Лес доменов: высшая граница безопасности каталога, объединяющая деревья доменов с общей схемой (Schema), конфигурацией и глобальным каталогом (Global Catalog).

2. Физическая архитектура и база данных

Физически служба каталога функционирует на выделенных серверах — контроллерах домена (Domain Controllers). База данных каталога размещается в файле ntds.dit (каталог C:\Winnt\Ntds) под управлением реляционного движка ESE (Extensible Storage Engine). Общие политики и скрипты входа реплицируются через защищенную системную папку Sysvol.

3. Роли хозяев операций FSMO

В Active Directory реализована многомастерная репликация, однако пять критических системных операций требуют абсолютной однозначности и закрепляются за конкретными контроллерами домена в виде ролей FSMO:

Масштаб ролиНаименование FSMOФункциональное назначение
На весь лесSchema MasterУправление изменениями в схеме каталога (добавление новых классов и атрибутов).
На весь лесDomain Naming MasterКонтроль уникальности имен при добавлении или удалении доменов из леса.
На доменPDC EmulatorСинхронизация точного времени по NTP, немедленная обработка изменений паролей.
На доменRID MasterВыделение пулов относительных идентификаторов RID контроллерам домена для генерации SID.
На доменInfrastructure MasterОбновление и поддержание целостности междоменных связей объектов и групп.
