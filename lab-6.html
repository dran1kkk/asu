Раздел 3.2.1 · Лабораторная работа № 6

Маршрутизатор и сегментация VLAN

Открыть PDF

Цель работы: Построить маршрутизируемую IP-сеть. Изучить разделение широковещательных доменов с помощью VLAN и настроить межсетевое взаимодействие через коммутатор 3-го уровня Catalyst 3560 и маршрутизатор Cisco 1841.

Порядок выполнения работы

  1. Собрать топологию сети в Cisco Packet Tracer: коммутатор Catalyst 3560, коммутатор 2960 и конечные рабочие станции.
  2. Создать виртуальные локальные сети VLAN 2, VLAN 3 и VLAN 4, распределив порты доступа (Access).
  3. Активировать функцию межсетевой маршрутизации на многоуровневом коммутаторе Catalyst 3560.
  4. Назначить IP-адреса виртуальным интерфейсам SVI для каждого сегмента VLAN.
  5. Проверить сквозную доступность узлов между различными широковещательными сегментами с помощью утилиты ping.

Конфигурация коммутатора Catalyst 3560:

Switch> enable
Switch# configure terminal
Switch(config)# ip routing
Switch(config)# vlan 2
Switch(config-vlan)# name VLAN2
Switch(config-vlan)# exit
Switch(config)# vlan 3
Switch(config-vlan)# name VLAN3
Switch(config-vlan)# exit
Switch(config)# interface vlan 2
Switch(config-if)# ip address 192.168.22.1 255.255.255.0
Switch(config-if)# no shutdown
Switch(config-if)# exit
Switch(config)# interface vlan 3
Switch(config-if)# ip address 192.168.33.1 255.255.255.0
Switch(config-if)# no shutdown
Switch(config-if)# end
Switch# write memory
