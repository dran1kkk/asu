Раздел 3.1.4 · Лабораторная работа № 4

Настройка служб Active Directory, DNS и DHCP

Открыть PDF Скачать DOC

Цель работы: Изучение принципов установки и администрирования служб сетевой операционной системы. Приобретение практических навыков работы с мастером настройки Active Directory (dcpromo), диспетчером DNS и пулами службы DHCP.

Программное обеспечение: Программа-симулятор NetAdmin.exe.

Краткие теоретические положения

Active Directory (AD DS) — централизованная база данных каталога, обеспечивающая единую точку входа и аутентификации в корпоративной сети. Домен выступает основной административной границей. Контроллер домена хранит базу NTDS.dit и реплицирует конфигурацию леса.

Протокол DHCP автоматизирует выдачу IP-адресов узлам на правах аренды из сконфигурированных областей (Scope). В домене Active Directory серверы DHCP подлежат обязательной авторизации администратором для предотвращения конфликтов адресации.

Порядок выполнения работы

  1. Запустить NetAdmin.exe, в меню «Сервис» открыть «Эмулятор настройки Active Directory» и зарегистрироваться под именем Admin с паролем password.
  2. Через командную строку виртуального рабочего стола запустить мастер dcpromo.exe.
  3. Создать новое доменное дерево в новом лесу с полным DNS-именем corp.com и NetBIOS-именем CORP.
  4. Указать пути размещения базы данных C:\Winnt\Ntds и общей папки Sysvol C:\Winnt\Sysvol.
  5. Выбрать режим «Настроить и установить DNS вручную» для детального изучения конфигурации зон. Сохранить параметры окна «Сводка» для отчета.
  6. После виртуальной перезагрузки сервера в диспетчере DNS добавить авторитетный сервер и настроить IP-адреса пересылки (192.168.1.1 и 192.168.2.1).
  7. Перейти в режим «Настроить DHCP», в списке серверов выбрать сервер Admin и выполнить процедуру его авторизации (индикатор сменится с красного на зеленый, статус — «Работает»).
  8. В окне «Мастер новой области действия» создать область (Scope) по номеру варианта (Area 1 – Area 10): ввести диапазон IP-адресов, маску подсети, исключения и обязательный IP-адрес маршрутизатора.
  9. В закладке «Регистрация» выбрать пункт «Получить IP-адрес», выполнить аренду адресов клиентскими хостами и проверить таблицу «Параметры хоста».
  10. Выполнить виртуальную передачу пакета данных между клиентами («Пакет отправлен») и проанализировать системный журнал событий.

Контрольные вопросы к защите отчета

  • 1. Чем отличаются режимы работы домена (смешанный и основной) и возможен ли обратный переход?
  • 2. С какой целью выполняется процедура авторизации серверов DHCP в каталоге Active Directory?
  • 3. Какие параметры передаются клиенту в составе области действия (Scope) помимо IP-адреса?
  • 4. Что происходит при попытке клиента обновить аренду адреса из деактивированной области (сообщение DHCPNACK)?
