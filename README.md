## О проекте

Статический сайт для студентов направления **09.03.02 «Информационные системы и технологии»** (7 семестр, 4 курс). Здесь собраны конспекты по сетевым службам и безопасности, описания лабораторных работ с командами и все файлы из методических указаний, которые можно скачать.

Сайт написан на чистых HTML, CSS и JavaScript: без фреймворков, сборщиков и внешних библиотек. Достаточно открыть `index.html`.

## Возможности

- 🌓 **Светлая и тёмная тема.** Выбор запоминается и синхронизируется между вкладками.
- ✅ **Трекер лабораторных.** Отмечайте сданные работы, прогресс сохраняется в браузере.
- 🧠 **Тренажёр самоконтроля.** Пять вопросов по DHCP, DNS, Cisco, Active Directory и RAID с разбором ответов.
- 🧮 **Калькулятор подсетей IPv4/CIDR.** Маска, обратная маска, адрес сети, широковещательный адрес и диапазон хостов.
- 📱 **Адаптивная вёрстка.** Работает на телефоне, планшете и компьютере.
- ♿ **Доступность.** Навигация с клавиатуры, `aria`-атрибуты, учёт настройки «уменьшить анимацию».

## Запуск локально

Сайт статический, поэтому сервер не нужен:

```bash
git clone https://github.com/dran1kkk/asu.git
cd asu
```

После этого откройте `index.html` в браузере. Если хотите запустить через локальный сервер:

```bash
python -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В **Source** выберите **Deploy from a branch**, ветку `main`, папку **/ (root)**.
3. После каждого `git push` во вкладке **Actions** запускается `pages-build-deployment`. Когда он завершится, сайт обновится (обычно за 1–2 минуты).

Если сайт показывает старую версию, обновите страницу через `Ctrl + F5`: браузер и CDN могут отдавать кэш.
