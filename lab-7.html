Раздел 3.2.2 · Лабораторная работа № 7

DHCP протокол и ретрансляция запросов (DHCP Relay)

Открыть PDF

Цель работы: Настроить автоматическое назначение IP-параметров хостам сети: сконфигурировать внутренний пул DHCP на маршрутизаторе Cisco 1841 и настроить агента ретрансляции ip helper-address на маршрутизаторе 2911 для обращения к выделенному серверу.

Конфигурация оборудования:

! 1. Пул адресов на маршрутизаторе 1841
Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.100
Router(config)# ip dhcp pool LOCAL_POOL
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8
Router(dhcp-config)# exit

! 2. Настройка DHCP Relay на подынтерфейсе роутера 2911
Router(config)# interface gigabitEthernet 0/0.2
Router(config-subif)# encapsulation dot1Q 2
Router(config-subif)# ip address 192.168.2.1 255.255.255.0
Router(config-subif)# ip helper-address 192.168.4.2
Router(config-subif)# exit
